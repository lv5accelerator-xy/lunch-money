# money-lunch 午饭小助手

纯前端小工具，无需安装，直接用浏览器打开 `index.html` 即可（也可以部署到 GitHub Pages）。

## 功能

### 1. 今天吃什么（抽奖转盘）
- 手动输入饭店名字添加到转盘，支持一次输入多个（逗号、顿号、换行分隔），自动去重。
- 至少 2 家饭店才能抽奖；点「开始抽奖」转盘旋转后停在随机的一家。
- 抽中后可点「去记一笔」，直接跳到记账页并把饭店名填进备注。

### 2. 饭钱记账（公共饭钱余额）
- 钱存在同事那里：用「存入」记录充值，用「消费」记录每天花销，余额自动扣除。
- 显示当前余额、按日均消费估算还够吃几天，透支时会提示补钱。
- 流水按日期分组，显示当天消费合计，以及累计存入 / 累计消费 / 本月消费。
- 金额以「分」为单位存储，不会出现 0.1 + 0.2 之类的浮点误差。

## 数据保存
数据保存在当前浏览器的 localStorage 中，**只在本机本浏览器有效**。
换电脑或清理浏览器数据前，请用「导出备份」保存 JSON 文件，之后可「导入备份」恢复。
